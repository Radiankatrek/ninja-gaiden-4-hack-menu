## 🧩 About

**Ninja Gaiden 4 Companion** is a curated list of Ninja Gaiden 4 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, checkpoint switcher
- **Quality-of-Life Helpers** — weapon catalog, skin manager, overlay notes
- **Research Notes** — combat layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Checkpoint Switcher — practice from any save point
- Show Hitboxes — visualize enemy and hazard hitboxes
- Replay Notes — record and review combat encounters
- Playback Speed — adjust training playback for study (0.1x to 5x)

### Wallhack
- Weapon Catalog — browse weapons, upgrades, costumes
- Custom Skin Notes — organize player cosmetics
- Enhanced Visibility — improved enemy and item highlights

### Aimbot
- Training Mode Notes — segment study on any encounter
- Camera Control — manually adjust camera angle for analysis
- Input Buffer Notes — chain complex combos in training
